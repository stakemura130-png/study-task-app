# 学習タスク管理アプリ 📚

司法試験・行政書士試験などの学習を、Trello風のカンバンで管理するためのWebアプリです。
データはお使いのブラウザ内（localStorage）に保存され、サーバーは不要です。

## 主な機能

- **共通カンバンボード**（Trello風）
  司法試験・予備試験・行政書士試験は学習内容が重なるため、タスクは**全試験で1つのボードに統合**。「未着手／学習中／復習／完了」の4カラムでカードをドラッグ＆ドロップして管理できます。
- **科目ごとのカラー設定**
  民法・商法などの科目とカラーを「科目・カラー設定」画面で管理。タスクに科目を割り当てると、カードがその色（左の色帯＋色付きタグ）で色分けされます。カード追加時はタイトルから科目を自動推定します。
- **タスク詳細・メモ**（Note風）
  各カードに条文・判例・要点などのメモを自由に書き込めます。科目もここで変更できます。
- **学習時間の記録**
  カードごとに学習時間を記録（+15分などのワンタップ or 任意入力）。
- **進捗・統計**
  完了率、ステータス内訳、直近7日間の学習時間グラフ、13週分の学習カレンダー（ヒートマップ）。
- **試験日カウントダウン（試験ごとに別）**
  タスクは共通でも、残り日数は試験ごとに個別表示。行政書士・予備・司法それぞれの試験日までの残り日数を画面上部に並べて表示します。残り30日以内は赤、90日以内は黄色で警告。

初回起動時は「行政書士試験」「予備試験」「司法試験」の試験日と、共通科目のサンプルタスクが入っています。

## 使い方

```bash
npm install      # 初回のみ
npm run dev      # 開発サーバー起動 → http://localhost:5173
```

本番ビルド：

```bash
npm run build    # dist/ に出力
npm run preview  # ビルド結果をプレビュー
```

## データの保存について

- すべてのデータはブラウザの **localStorage** に保存されます。
- 同じブラウザ・同じPCであれば、閉じても次回そのまま残ります。
- ブラウザのデータを消去すると学習記録も消えます。複数端末での同期は未対応です。

## 技術構成

- React 18 + TypeScript + Vite
- 状態管理：React Hooks + localStorage（外部ライブラリ不使用）
- ドラッグ＆ドロップ：HTML5 ネイティブ DnD

## ディレクトリ構成

```
src/
  types.ts            型定義（Task / Exam / 学習ログ）
  utils.ts            日付・時間のユーティリティ
  storage.ts          localStorage 読み書き＋初期サンプル
  useStore.ts         アプリ全体の状態と操作（追加/移動/記録など）
  App.tsx             画面の組み立て
  components/
    Sidebar.tsx       ナビゲーション・試験日一覧
    Board.tsx         共通カンバン（カラム・カード・DnD）
    Countdown.tsx     試験ごとのカウントダウン（横並び）
    TaskModal.tsx     タスク詳細（科目・メモ・学習時間）
    ExamModal.tsx     試験日の作成・編集
    SubjectSettings.tsx 科目・カラー設定
    Stats.tsx         進捗・統計・カレンダー（全試験共通）
```
